# 保存済み発走前評価と結果の照合（試作）

既存の取得・評価・画面を変更しません。評価の作り直し、購入、収支計算、自動的なモデル変更はしません。

## 適用

```bash
unzip -n nankan-compare-20261023.zip -d /tmp/nankan-compare-20261023
python /tmp/nankan-compare-20261023/apply_compare.py
```

## 実行

```bash
python nar_compare_prerace.py
```

標準の保存先 `data/prerace_runs` の完了記録を、`data/processed/horse_history.csv` の確定結果と照合します。公式月次データを追加して画面の「履歴を作成・更新」で履歴CSVに反映した後に実行してください。結果を自動取得する機能は含みません。

同じレースに複数の完了記録がある場合、ファイル保存完了時刻が最も早い記録を使用します。同時刻は保存パス順。最初の記録が検証に失敗しても他の記録に取り替えません。レース結果に合わせて記録を選ぶことを防ぎます。失敗・未完了の取得記録は比較対象に数えません。

保存済み出力・取得原文のハッシュ、取得・採点・書き出しと発走予定時刻の順序、レースと馬の一致を確認します。取消・除外・中止・同着、部分結果は現時点ではレース単位で除外し、理由を残します。馬の識別情報の表記差も保守的に除外します。

新規フォルダ `data/prerace_comparisons/実行時刻-識別子` に以下を保存します。

- `summary.json`：比較レース数、除外理由、上位3頭の捕捉数、評価最上位馬の実着順、入力ハッシュ。
- `comparison-XXXX.csv`：馬ごとの事前評価点・順位・確かさ・実着順・順位差。

同点は同順位で、評価3位以内の対象が4頭以上になることがあります。対象頭数を併記します。欠測には順位を付けません。順位差が正なら評価より着順が下、負なら評価より着順が上です。「確かさ」は既存評価のデータ充足指標で、的中確率ではありません。

保存済みの発走前評価がない場合は「照合0R」と出力します。処理自体の確認であり、実レースの比較成功ではありません。現在のバックアップには発走前評価がなく、実データでの照合成功は未確認です。時計とハッシュはローカル記録に依存し、独立した取得時刻証明にはなりません。月次結果がまだないレースは除外理由として表示されます。
