# 発走前の自動保存（試作）

Codespaces/Linux用。購入機能はありません。既存の評価・画面は変更しません。

## 適用

リポジトリ直下でZIPを展開して適用します。

```bash
unzip -n nankan-watch-20261023.zip -d /tmp/nankan-watch-20261023
python /tmp/nankan-watch-20261023/apply_watch.py
```

## 開催日に起動

画面で履歴を準備した後、実際に開催している場を指定します。

```bash
python -u nar_watch_prerace.py --venue 大井
```

指定可能：浦和・船橋・大井・川崎。日本時間の当日限定。初回に公式出走表1〜12Rを2秒間隔で取得し、検証できたRと予定発走時刻、取得できなかったRの理由を表示します。開催場の自動判定や日々の定時起動ではありません。確認不能なRは監視しません。時刻変更の再発見は行いませんが、取得・評価時には公式ページの時刻で発走前か再検証します。

予定発走5分前から1分前までに、既存の取得・評価処理を実行します。失敗時は60秒以上空けて最大3回。30秒間隔で時刻を確認します。完了・見逃し・3回失敗のRは繰り返しません。当日分の全対象が終了したら停止します。中止はCtrl+C。変更が必要な日程、発見できなかったRは画面から手動で取得してください。

監視状態は `data/prerace_watch/YYYY-MM-DD-場コード.json`、評価は既存の `data/prerace_runs` に保存します。画面を再読み込みすると保存済み記録に表示されます。同じ保存先での二重起動をロックで防止。再起動時は出力ハッシュを確認した完了記録を復元し、取得の重複を抑えます。処理途中の強制終了後に未完了分の再試行はあり得ます。状態ファイルは削除・変更せず保持してください。

**Codespacesが停止・スリープすると監視も停止します。** 常時稼働の仕組みは含まれません。Streamlitとは別ターミナルで起動してください。履歴CSV・評価記録・監視状態はこの追加コードのGitコミットだけではバックアップされません。

## 検証と限界

監視時間窓、遅延時の見逃し、再試行上限と間隔、日付変更、複数Rの時刻更新、取得エラーの明示、再起動時の復元をテストします。公式の発走前実データでの一連の成功は未確認です。ローカル時計依存、既存v2評価は確率校正未実施、回収率120%の達成未確認。人気・オッズは採点に使用しません。
